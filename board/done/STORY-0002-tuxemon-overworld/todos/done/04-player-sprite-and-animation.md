# Add player sprite with walk animations

Load the adventurer.png spritesheet (16x32 frames, 4 rows x 3 cols).

Set up Phaser animations for 4 directions:
- walk-down:  row 0 frames (walk1, idle, walk2)
- walk-left:  row 1 frames
- walk-right: row 2 frames
- walk-up:    row 3 frames

Place the player sprite on the map at a starting tile position. Show the
idle frame initially.

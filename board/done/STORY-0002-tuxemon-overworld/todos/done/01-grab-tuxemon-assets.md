# Grab Tuxemon assets and add attribution

Copy the minimum assets from the Tuxemon repo into `public/assets/`:

- `core_outdoor.png` + `core_outdoor_nature.png` tilesets (16x16 tiles)
- `adventurer.png` player spritesheet (16x32 frames, 4x3 grid)

Add a `CREDITS.md` or `LICENSE-ASSETS.md` at the repo root with proper
CC-BY-SA 4.0 attribution for Tuxemon.

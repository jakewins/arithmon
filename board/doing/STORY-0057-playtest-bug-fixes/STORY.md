# STORY-0057: playtest-bug-fixes

## Description

A collection of bugs found during playtesting that need to be fixed. These range from collision issues to missing interactions and rendering glitches.

## Acceptance Criteria

- [ ] Player can walk up to fences from the north without stopping a tile too early
- [ ] Signs in the first town are readable when the player interacts with them
- [ ] Interior rendering of the two southern houses in the first town matches upstream Tuxemon (no cut-off display cases)
- [ ] Pine trees on the road north of the first town block the player from all directions (no walking through from the west)
- [ ] Combat technique selection shows power/strength and any special properties of each attack
- [ ] Saving via the menu persists all current map state immediately (not only on map transitions)
